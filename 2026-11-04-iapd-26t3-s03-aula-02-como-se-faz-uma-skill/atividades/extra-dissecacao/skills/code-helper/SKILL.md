# Code Helper

This skill helps you with code. It can review code, fix code, write code, explain code and improve code quality.

## Instructions

- Always write clean code.
- Follow best practices.
- Be careful with bugs.
- Use good variable names.
- Add comments when necessary.
- Make sure the code works.
- Consider edge cases.
- Think about performance.
- Think about security.
- ALWAYS be thorough.
- NEVER make mistakes.

## Output

Provide the result to the user in a helpful way.
