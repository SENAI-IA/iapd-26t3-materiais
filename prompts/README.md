# Prompts compartilhados

Exemplos de prompt que funcionaram em aula ou no projeto, um arquivo por prompt.

Nome do arquivo: `<tema>-<o-que-faz>.md` (ex.: `review-pedir-revisao-de-pr.md`).

Cada arquivo tem três partes:

```markdown
# Título

**Quando usar:** uma frase.
**Ferramenta testada:** Kiro / Claude Code / Copilot (e data).

## Prompt

(o texto, exatamente como foi usado)

## O que saiu

(resumo do resultado e o que precisou corrigir)
```

Alunos contribuem por Pull Request a partir do repo da equipe. Professores revisam e fazem merge.
